# Grid Viewer

A single-page web app for viewing CIM / CGMES power grid models: a geographic view on
a map and a schematic single-line diagram, with hover details, search and power-flow
results. It runs entirely in the browser; nothing is uploaded.

## Run

Serve the repository root over HTTP and open the viewer:

```bash
python -m http.server 8000
# http://localhost:8000/viewer/
```

Then drop files onto the page or use **Open files…**. With the samples generated by
`synthetic_cim_generator.py` in the repository root, the **Sample** buttons load them
directly, as does a URL such as `http://localhost:8000/viewer/?file=../synthetic_grid_CGMES.zip`.

Opening `index.html` straight from disk (`file://`) also works for drag-and-drop and
**Open files…**; only the sample buttons need HTTP. Leaflet and JSZip are loaded from
CDNs and map tiles from Esri / OpenStreetMap, so an internet connection is needed.

## Supported input

* **CGMES 2.4.15** as a `.zip` or as separate profile `.xml` files (EQ, TP, SSH, SV, GL, DL;
  select several files at once).
* **CIM17 RDF/XML** as written by cim-graph (`rdf:about="urn:uuid:…"`, typed SI units).

What is shown depends on the profiles present:

| Profile | Used for |
|---|---|
| EQ | Substations, voltage levels, buses, lines, transformers, generators, loads, shunts, thermal limits |
| TP / SV | Bus voltages, branch flows, loading, losses |
| SSH | Setpoints and dispatch when there is no SV |
| GL | Geographic view (WGS84 positions on the map) |
| DL | Schematic view; without DL an automatic force-directed layout is used |

## Features

* **Geographic / Schematic switch**; the selected object stays selected and centred.
* **Colour by** voltage level, branch loading (vs. PATL ratings) or bus voltage (pu).
* **Flow animation**: dots move in the direction of active power, faster with higher loading.
* **Hover** for a summary, **click** for details (connected equipment, per-circuit data,
  raw CIM attributes); `Esc` clears the selection.
* **Search** by name, **labels**, **equipment symbols**, and several base maps.

## Files

* `index.html`, `style.css`: page and styling
* `cim.js`: RDF/XML parsing (CGMES and CIM17), network model, automatic layout
* `app.js`: rendering (Leaflet), interaction, colour modes, flow animation
